# ⚡ MVS Electrical

### Electrical & Plumbing Order Management System

MVS Electrical is a simple mobile-friendly web application for creating Electrical and Plumbing order forms.

---

## 🌐 Website

**MVS Electrical Order Form**

Electrical and Plumbing items can be selected and quantity can be entered directly from the website.

---

## ✨ Features

- ⚡ Electrical Order Form
- 🚰 Plumbing Order Form
- 📱 Mobile Friendly
- 💻 Desktop Friendly
- 🧾 Order Form Layout
- 🔢 Automatic S.No
- ➕ Automatic Quantity Total
- 📄 PDF Generation
- 📝 Customer Name
- ☎️ Phone Number
- 📱 Cell Number
- 📅 Date
- 📦 Items loaded from JSON
- 👀 Only entered Qty items appear in PDF
- 🔢 PDF S.No automatically starts from 1
- 🔄 Electrical and Plumbing can be included in the same PDF
